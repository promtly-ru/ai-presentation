# AI-автоматизация для бизнеса — презентация

Пример работы [Promptly](https://promtly-ru.github.io/): веб-презентация с анимациями, интерактивным калькулятором и файлами для скачивания.

- Смотреть: https://promtly-ru.github.io/ai-presentation/
- PDF и PowerPoint: папка `downloads/`

Пересобрать PDF, PPTX и превью после правок `index.html`: `python tools/build_downloads.py` (нужны Microsoft Edge, `pip install pillow python-pptx`).
